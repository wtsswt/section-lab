# 截面实验室 · SECTION LAB

用平面切立体，实时看截面形状与截交线判型；也可做两立体相贯与三视图。

在线：<https://wtsswt.github.io/section-lab/>

## 功能

- **截交线与相贯线两种模式**，页面左上角切换
- **选择立体**：正方体、正四面体等柏拉图多面体，正棱柱、正棱锥（底面边数 3–16 可调），圆柱、圆锥、球
- **切割平面**：倾角 θ、方位 φ、偏移 h 三个参数，可自动旋转；实时给出平面方程并与图形联动
- **截面真形**：给出当前截面的真实形状与名称，标注长短轴与特征点
- **剖面存储**：把感兴趣的截面存下来回看
- **三视图**：按第一角投影生成主视 / 侧视 / 俯视，可导出 PNG

## 截交线判型

多面体按棱线求交，截面必为多边形；回转体按解析曲线求交，截面是真正的曲线，周长与面积按真实尺度积分。

| 立体 | 截交线 | 判据 |
| --- | --- | --- |
| 圆柱 | 圆 | 截平面垂直于轴线（β = 90°） |
| 圆柱 | 椭圆 | 0° < β < 90°，斜截 |
| 圆柱 | 矩形 | 截平面平行于轴线（β = 0°） |
| 圆柱 | 椭圆 + 直线 | 椭圆超出柱高，端面补一段直线 |
| 圆锥 | 圆 | β = 90° |
| 圆锥 | 椭圆 | β > 半顶角 α |
| 圆锥 | 抛物线 | β = α，截平面平行于一条素线 |
| 圆锥 | 双曲线 | β < α，截平面与上下锥面都相交 |
| 圆锥 | 三角形 | 截平面过锥顶 |
| 球 | 圆 | 恒为圆，半径 r = √(R² − h²) |
| 多面体（含棱柱、棱锥） | 多边形 | 边数等于被截的面数 |

β 为截平面与轴线夹角，α 为圆锥半顶角（本模型约 26.4°）。圆锥有限，曲线到锥底会被底圆截断，界面标出「被底面截断」并补出那段弦。

截面视图里虚线是主轴（椭圆的长短轴），四个空心圈是最左 / 最右 / 最高 / 最低四个特征点，即作图时要先定的特殊位置点。

## 相贯线

主体固定为竖直圆柱（R₁ = 1.00），从体可选圆柱或球，可调半径 R₂、轴线高度 z₀、轴线偏距 e。

求法：在从体表面参数域 (u, v) 上采样主体隐函数 f = x² + y² − R₁²，用 marching squares 取 f = 0 的等值线，再串成闭合折线。对柱-柱、柱-球通用，不依赖解析特例。

| 情形 | 相贯线 | 判据 |
| --- | --- | --- |
| 柱-柱 不等径正交 | 两条闭合空间曲线 | R₂ < R₁，从体一进一出各留一个孔 |
| 柱-柱 等径正交 | 两条平面曲线（椭圆） | R₁ = R₂，落在两个对称平面内，正投影为两条相交直线 |
| 柱-柱 偏交 | 一条闭合空间曲线 | e ≠ 0，两轴线不相交，两条交线相接 |
| 柱-球 同轴 | 两个圆 | 球心在圆柱轴线上，z = z₀ ± √(R₂² − R₁²) |
| 柱-球 偏心 | 空间曲线 | e ≠ 0，不再对称 |

实线为两块表面都朝向观察者的部分，虚线为被遮挡部分；主体被从体占住的面片按隐函数裁掉（挖孔），相贯线正好落在孔口边缘。等径正交的结论可在「视角 → 主视」下直接验证：两条椭圆投影成 X 形的两条直线。

## 三视图

相贯模式下右下角实时给出主视 / 俯视 / 左视，随参数联动：

- 三视图共用一套比例，按「长对正、高平齐、宽相等」摆位
- 被另一立体挡住的轮廓段直接断开——相贯后那里已无棱线，画虚线是错的
- 相贯线的投影：实线为可见段，虚线为被遮挡段；俯视图中积聚在主体的圆上，左视图中积聚在从体端面圆上

## 视角

右侧四个按钮：主视 / 俯视 / 左视 / 立体。

- 相贯模式下前三个画的是真正的正交视图，与三视图卡片共用同一段绘制代码，只是铺满主画布。不把 3D 相机摆到那个角度的原因：两段管是开口薄壁，正对轴线看只剩一圈轮廓，像没画出来。
- 截面模式下这三个按钮只改相机角度，场景仍按 3D 渲染。
- 立体兼作复位，相机角度与缩放一起回默认，因此不单设复位按钮。正交视图里一拖动就退回 3D，并从该方向接着转；滚轮改的是该视图的比例。

## 使用

浏览器打开 `index.html`，或访问上面的在线地址。「底面棱数」滑杆只在棱柱 / 棱锥时出现；圆柱、圆锥表面细分固定为 72 段，仅用于描轮廓，不参与截交线求解。

手势：单指拖拽旋转，双指捏合缩放，双击复位视角。
