# 截面实验室 · SECTION LAB

一个单页交互式工具，用平面去切立体图形，实时观察截面形状的变化，并给出截交线的类型判断。

## 功能

- **选择立体**：正方体、正四面体等多种多面体与圆柱、圆锥、球，可一键切换
- **切割平面**：倾角 θ、方位 φ、偏移 h 三个参数控制切割平面，支持自动旋转
- **平面方程**：实时给出平面方程，与图形联动
- **截面视图**：当前截面的真实形状（真形）与名称，标注长轴/短轴与特征点
- **截交线判型**：判断截交线类型并给出判据，见下节
- **剖面存储**：把感兴趣的截面存起来，随时回看
- **三视图**：按第一角投影生成主视 / 侧视 / 俯视图，可导出 PNG

## 截交线判型

截面按解析解计算，不是折线近似，因此曲线光滑、周长面积按真实尺度积分。

| 立体 | 截交线 | 判据 |
| --- | --- | --- |
| 圆柱 | 圆 | 截平面垂直于轴线（β = 90°） |
| 圆柱 | 椭圆 | 0° < β < 90°，斜截 |
| 圆柱 | 矩形 | 截平面平行于轴线（β = 0°） |
| 圆柱 | 椭圆 + 直线 | 椭圆超出柱高，端面上补一段直线 |
| 圆锥 | 圆 | β = 90° |
| 圆锥 | 椭圆 | β > 半顶角 α |
| 圆锥 | 抛物线 | β = α，截平面平行于一条素线 |
| 圆锥 | 双曲线 | β < α，截平面与上下锥面都相交 |
| 圆锥 | 三角形 | 截平面过锥顶 |
| 球 | 圆 | 恒为圆，半径 r = √(R² − h²) |
| 多面体 | 多边形 | 平面与各面相交，交点为平面与棱的交点 |

β 是截平面与轴线的夹角，α 是圆锥半顶角（本模型中约 26.4°）。圆锥有限，曲线到锥底时会被底圆截断，界面会标出「被底面截断」并在底面上补出那段弦。

截面视图里的虚线是主轴（椭圆的长轴/短轴），四个空心圈是最左/最右/最高/最低这四个特征点——也就是截交线作图时要先定的特殊位置点。

## 使用

直接用浏览器打开 `index.html` 即可，无需安装依赖、无需构建。页面为完全自包含的单文件实现（样式与脚本全部内联），不引用任何外部资源。

也可访问线上版本：<https://wtsswt.github.io/section-lab/>

面板上的「面数密度」只影响圆柱/圆锥侧面轮廓的细分程度，用来对比棱柱、棱锥逼近；截交线本身按解析曲线求解，不随该值变化。

## 移动端

已适配手机与平板：

- **手机（≤760px）**：单列布局，三维视图置顶、切割平面控制条移到画布下方并排成两列，避免小屏上控件挤压画面；字号与点击区域放大，滑块手柄加大便于手指拖动。
- **平板（≤960px）**：视图独占整行铺满宽度，左右两块面板在下方并排；横放时恢复三栏。
- **手势**：单指拖拽旋转、双指捏合缩放、双击（或快速双点）复位视角。
- 顶部栏、页脚等处的安全区留白适配刘海屏与圆角屏。
