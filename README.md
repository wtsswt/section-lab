# 截面实验室 · SECTION LAB

一个单页交互式工具，用平面去切立体图形，实时观察截面形状的变化，并给出截交线的类型判断。

## 功能

- **两种模式**：截交线（平面切立体）与相贯线（两个立体表面相交），点左上角切换
- **选择立体**：正方体、正四面体等柏拉图多面体，正棱柱、正棱锥（底面边数 3–16 可调），以及圆柱、圆锥、球
- **平面立体与曲面体分开处理**：多面体按棱线求交，截面一定是多边形；回转体按解析曲线求交，截面是真正的曲线
- **切割平面**：倾角 θ、方位 φ、偏移 h 三个参数控制切割平面，支持自动旋转
- **平面方程**：实时给出平面方程，与图形联动
- **截面视图**：当前截面的真实形状（真形）与名称，标注长轴/短轴与特征点
- **截交线判型**：判断截交线类型并给出判据，见下节
- **剖面存储**：把感兴趣的截面存起来，随时回看
- **三视图**：按第一角投影生成主视 / 侧视 / 俯视图，可导出 PNG

## 截交线判型

回转体的截面按解析解计算，不是折线近似，因此曲线光滑、周长面积按真实尺度积分。多面体（正方体、正四面体、棱柱、棱锥等）本来就是平面立体，截面必然是多边形，截交线由平面与各条棱的交点连成。

| 立体 | 截交线 | 判据 |
| --- | --- | --- |
| 圆柱 | 圆 | 截平面垂直于轴线（β = 90°） |
| 圆柱 | 椭圆 | 0° < β < 90°，斜截 |
| 圆柱 | 矩形 | 截平面平行于轴线（β = 0°） |
| 圆柱 | 椭圆 + 直线 | 椭圆超出柱高，端面上补一段直线 |
| 圆锥 | 圆 | β = 90° |
| 圆锥 | 椭圆 | β > 半顶角 α |
| 圆锥 | 抛物线 | β = α，截平面平行于一条素线 |
| 圆锥 | 双曲线 | β < α，截平面与上下锥面都相交 |
| 圆锥 | 三角形 | 截平面过锥顶 |
| 球 | 圆 | 恒为圆，半径 r = √(R² − h²) |
| 多面体（含棱柱、棱锥） | 多边形 | 平面与各面相交，交点为平面与棱的交点，边数等于被截的面数 |

β 是截平面与轴线的夹角，α 是圆锥半顶角（本模型中约 26.4°）。圆锥有限，曲线到锥底时会被底圆截断，界面会标出「被底面截断」并在底面上补出那段弦。

截面视图里的虚线是主轴（椭圆的长轴/短轴），四个空心圈是最左/最右/最高/最低这四个特征点——也就是截交线作图时要先定的特殊位置点。

## 相贯线

切到「相贯线」模式后，主体固定为竖直圆柱（R₁ = 1.00），从体可选圆柱或球，可调半径 R₂、轴线高度 z₀、轴线偏距 e。

求交方法：在从体表面的参数域 (u, v) 上采样主体隐函数 `f = x² + y² − R₁²`，用 marching squares 取 f = 0 的等值线，再把这些等值线段串成闭合折线。这样对圆柱-圆柱、圆柱-球都通用，不依赖任何解析特例。

判型规则：

| 情形 | 相贯线 | 判据 |
| --- | --- | --- |
| 柱-柱 不等径 正交 | 两条闭合空间曲线 | R₂ < R₁，从体一进一出各留一个孔 |
| 柱-柱 等径 正交 | 两条平面曲线（椭圆） | R₁ = R₂，曲线落在两个对称平面内，正投影为两条相交直线 |
| 柱-柱 偏交 | 一条闭合空间曲线 | e ≠ 0，两轴线不相交，两条交线相接 |
| 柱-球 同轴 | 两个圆 | 球心在圆柱轴线上，z = z₀ ± √(R₂² − R₁²) |
| 柱-球 偏心 | 空间曲线 | e ≠ 0，不再对称 |

显示上：实线是两块表面都朝向观察者的部分（可见），虚线是被遮挡的部分。主体上被从体占住的面片按隐函数裁掉（挖孔），相贯线正好落在孔口边缘。每条曲线上的空心圈是最高点 / 最低点，也就是作图时先要定的转向轮廓线上的点。

渲染上有两处是特意处理的：

- **正交投影**。相贯模式用正交而不是透视，否则沿轴向伸展的水平圆柱会因为近大远小看起来像圆台。
- **离屏着色层**。每个立体先画进自己的离屏画布，层内用不透明色 + 同色描边，再整体按透明度合成一次。逐片半透明填色时，相邻面片的交界会漏出一条 1px 的背景，密排起来就是一层网格状的马赛克。转动视角时先降网格密度、松手再补一帧满精度，手机上也能跟手。

等径正交那条结论可以在「视角 → 水平」下直接验证：两条椭圆曲线投影成 X 形的两条直线。

## 三视图（相贯模式）

右下角实时给出第一角投影的主视 / 俯视 / 左视，随参数联动，不用点按钮：

- 三个视图共用一套比例，并且按「长对正、高平齐、宽相等」摆位：主视与俯视左右对齐，主视与左视上下对齐
- 轮廓被另一立体挡住的段落直接断开——相贯以后那里已经没有棱线了，画虚线反而是错的
- 相贯线的投影：金色实线是可见段，虚线是被遮挡段。俯视图里它积聚在主体的圆上，左视图里积聚在从体的端面圆上，正好对上教材「用积聚性求相贯线」的思路

## 使用

直接用浏览器打开 `index.html` 即可，无需安装依赖、无需构建。页面为完全自包含的单文件实现（样式与脚本全部内联），不引用任何外部资源。

也可访问线上版本：<https://wtsswt.github.io/section-lab/>

「底面棱数」滑杆只在选中棱柱或棱锥时出现，用来改变底面正多边形的边数；其余立体不显示这个控件。圆柱、圆锥没有面数可调——它们是曲面体，表面细分固定为 72 段，只用于描出轮廓，不参与截交线求解。

## 移动端

已适配手机与平板：

- **手机（≤760px）**：单列布局，三维视图置顶、切割平面控制条移到画布下方并排成两列，避免小屏上控件挤压画面；字号与点击区域放大，滑块手柄加大便于手指拖动。
- **平板（≤960px）**：视图独占整行铺满宽度，左右两块面板在下方并排；横放时恢复三栏。
- **手势**：单指拖拽旋转、双指捏合缩放、双击（或快速双点）复位视角。
- 顶部栏、页脚等处的安全区留白适配刘海屏与圆角屏。
